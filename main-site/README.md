# Main site

This archive contains the publicly served HTML in `pages/`, stylesheet in `styles/`, JavaScript in `scripts/`, and referenced local visual assets in `assets/`. Original asset subpaths are preserved below `assets/`; files were not renamed or modified.

No separate component or configuration files were publicly exposed. These are deployment files retrieved from the public site, not a claim that they are the original private development repository or its backend source.

Nexora Academy was built by a university team, with Murad Shirinov as a contributor/builder.
